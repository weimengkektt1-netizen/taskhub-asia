📜 平台规则

👤 账户与角色

  • 注册时请选择身份：下单人 或 接单人，注册后不可随意更改。
  • 接单人昵称全网唯一，每位接单人拥有独立 UID 用于识别。
  • 下单人与接单人均需在平台钱包充值后，才能下单 / 接单。

💰 押金与担保

  • 下单押金 = 接单押金 = 订单金额，全程由平台托管。
  • 下单人发布订单时托管押金，接单人接单时冻结同额押金。
  • 订单完成并经管理员审核后，双方押金自动退还；被驳回的订单同样退还。

🎯 资格匹配

  • 段位单：接单人历史最高段位 ≥ 订单目标段位才可接取。
  • 巅峰单：接单人历史最高巅峰分 ≥ 订单目标巅峰分才可接取。
  • 接单人资料须经管理员审核认证，才会展示在打手大厅。

📋 接单方式

  • 无指定接单人：订单自动进入接单大厅，符合资格的打手付押金领取。
  • 有指定接单人：订单自动推送至该接单人，并发送通知提醒。

💸 佣金与平台抽佣

  • 订单完成审核后，佣金自动打入接单人钱包。
  • 平台按接单人等级抽佣：LV0/LV1 15% · LV2 12% · LV3 10% · LV4 8% · LV5 5% · LV6 3%。

⭐ 经验与等级

  • 每完成一单按订单价值获得经验（RM1 = 1 exp），经验用于升级等级。
  • 等级越高，平台抽佣越低、徽章越尊贵（详见上方等级体系）。

🏧 提现规则

  • 钱包余额（含佣金）可随时申请提现。
  • 提现由管理员审核，转账完成后自动扣减钱包余额，可在钱包查看转账凭证。

🛡️ 诚信与安全

  • 严禁私下交易、共享账号、恶意刷单等违规行为，违者将冻结账户。
  • 任何问题请通过右下角 WhatsApp 客服 联系平台，谨防诈骗。

1. 如何注册并选择身份？

注册时选择「下单人」或「接单人」身份。下单人发布订单并托管押金；接单人需先提交打手资料，审核通过后即可接单。注册后身份不可随意更改。

2. 如何充值？多久到账？

在「我的钱包」点击充值，按页面显示的收款二维码或银行账户转账，上传转账截图后提交。管理员审核通过后金额自动入账，通常几分钟至 1 小时内到账。

3. 如何下单？

在「发布订单」选择段位上分或巅峰上分，填写当前/目标段位、价格、完成时间；可指定打手（昵称或 UID），不指定则自动进入接单大厅。下单前请确保钱包余额充足。

4. 如何接单？有什么资格要求？

在「接单大厅」或指定订单中选择符合资格的单子，支付押金后接取。段位单要求历史最高段位 ≥ 目标段位；巅峰单要求历史最高巅峰分 ≥ 目标巅峰分。

5. 押金如何收取与退还？

下单押金 = 接单押金 = 订单金额，由平台托管。订单完成并经管理员审核后，双方押金自动退还至钱包；订单被驳回同样全额退还。

6. 佣金如何计算与发放？

订单完成后，平台按接单人等级抽取一定比例，剩余佣金自动打入接单人钱包。抽佣比例：LV0/LV1 15%、LV2 12%、LV3 10%、LV4 8%、LV5 5%、LV6 3%。

7. 经验与等级如何获得？

每完成一单按订单价值获得经验（RM1 = 1 exp）。等级越高抽佣越低、徽章越尊贵，每月可冲击排行榜赢取荣誉。

8. 如何提现？最低金额？

在「我的钱包」申请提现，最低 RM50。提交申请后管理员审核并转账，转账完成后自动扣减余额，可在提现记录中查看转账凭证。

9. 订单多久能完成？

下单时填写希望完成的时间（如 3 天内/5 天内），打手须在约定时间内完成并提交完成证明。超时未完成可联系客服介入处理。

10. 遇到纠纷怎么办？

所有订单均经平台审核。如打手未按时完成、资料不实等，可提交完成证明并联系客服，平台将按规则仲裁：押金全额退还、违规方按情节处理。

11. 代充/代送怎么购买？

在「代充代送」版块选择商品，点击「购买」复制商家微信号，添加后发送商品名称即可下单。该版块货品全部经由网站担保。

12. 怎么联系客服？

页面右下角 WhatsApp 客服按钮（wa.me/60175468526），工作日 10:00 - 22:00 在线，通常几分钟内回复。
